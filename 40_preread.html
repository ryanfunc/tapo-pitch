Tapo 归因底座：从 GA4 导出到可校准的 MTA

多触点归因的八成成败，不在模型，在建模之前——在 GTM 有没有把 click ID、consent 状态、和能把"同一个人"串起来的身份键，一起落进 BigQuery。模型三个月后再建都不晚；这三样，晚一个月就永久缺一个月的历史。

GTM · CAPI · CMP · CONSENT MODE V2 · GA4 → BIGQUERY · MARKOV / SHAPLEY MTA · REVERSE ETL

01先把口径分层，再谈模型

同一笔订单，四个平台给出四个答案，且没有任何两个能加得起来。这不是谁在撒谎，是四套自归因在各自口径里都对。

层回答的问题可信度用来干什么
L1 平台自报平台认为它带来了多少平台内可信，跨平台不可加日常出价、素材迭代
L2 仓内 MTA在可观测路径里，谁的边际贡献大中（取决于身份覆盖率）预算再分配、渠道/素材排序
L3 增量实验如果关掉它，会发生什么高，但频率低校准 L2、回答董事会
最常见的两个致命错① 用 L1 做结算（预算按"谁喊得响"分）；② 用 L2 做日内调优（模型有滞后）。L2 定方向，L1 调速，L3 定生死。

02一条管道，四个阀门，分两路走

GTM、CAPI、CMP、Consent Mode v2 不是四个项目，是同一根管子上的四个阀门。装对了，MTA 只是管末的一个查询。

触点
Meta / Google / TikTok / KOL / 邮件 / 自然与站内搜索 —— 全部带 fbclid · gclid · ttclid · UTM
采集
Shopify Web Pixels（官方唯一的客户端 checkout 采集口）+ 服务端 sGTM（自有子域）+ CMP 让每个事件带上 consent 状态
分两路
路 A 实时回传：Meta CAPI / Google Enhanced Conversions → 喂算法（算法只吃这条）
路 B 入仓：GA4→BigQuery 全量导出 + 服务端事件日志 → 真相层。用 event_id 去重
建模
dbt：身份解析（邮箱 hash 确定性 + visitor_id 概率）→ 路径重建 → Markov / Shapley 多触点归因 → 实验校准 → 预算建议
输出
看板（渠道 / 素材 / 人群 / 新老客 / consent 分层）+ 反向 ETL 把仓内真相回灌 Meta / Google / TikTok

03为什么是 sGTM，而不是三个原生插件

三个官方渠道能给你"有服务端回传"，给不了"三家对得上账"。这一节是整份方案的分水岭。

一进三出 → 一进一出
网页版 GTM 同时挂三个 tag，用户手机实际发了三次请求：拦截名单对三家不一样，用户关页面还会掐断队尾那条。sGTM 让手机只向自家域名发一次，机房内再发三次。
三套插件 = 三套标尺
Meta / Google / TikTok 三个插件各有自己的触发钩子与 event_id 规则，同一个 Purchase 在三家后台是三个数，漏斗对不上。在源头只生成一次 ID，才谈得上跨平台对账。
部署决定 Cookie 寿命
裸 CNAME 指向第三方托管域名，会被 Safari 判为"CNAME 伪装"、Cookie 压回 7 天；同源路径反代（www.tapo.com/metrics）才是官方推荐做法。上了 sGTM 不等于解决了这件事。

04两阶段：采集现在开，模型以后建

核心原则只有一句：采集与建模解耦。历史不采，以后补不回来；转化量不够，模型算出来的只是噪声的形状。

阶段周期做什么验收
P0 审计1 周GTM / CMP / CAPI / GA4 / BQ 现状 gap 清单 + 90 天路线图能指出哪几笔转化被重复计
P1 采集3–4 周sGTM + CAPI/EC 双发 + Consent Mode v2 + Web Pixels + BQ 全量落库 + 身份字段重复计 = 0；深事件覆盖 ≥95%；EMQ ≥7
P2 建模4–6 周dbt 分层 + 身份图 + 路径表 + 四模型归因 + 看板 + 反向 ETL可归属转化 ≥60%；模型分歧可解释
P3 运营化持续月度复盘 + 预算再分配建议 + 季度实验校准（+ 可选 MMM）每条建议可追溯到实验或区间

05不许诺的部分，正是可信的部分

天花板
匿名期 + 跨设备 + 拒同意 + 线下零售，结构性看不到。能还原 60–85% 的路径就是好成绩，其余靠 MMM、实验、结账后问卷兜底。
Amazon
DTC 的 MTA 看不见站内搜索，也看不见"站上看完去 Amazon 下单"。两套口径不硬拼：DTC 用 MTA，跨渠道用 MMM + 溢出测量。
承诺
不承诺 ROAS 涨幅。承诺三件可验收的事：口径清楚、决策变快、无效花费可被指认；每个结论都可被实验推翻。
